# DualMind AI Studio (Android)

Android alpha. Native WebView shell with OpenAI, Anthropic, and OpenAI-compatible API support. No bundled GGUF inference engine yet. API keys are entered locally and are not committed to GitHub.

## Build
GitHub Actions → Build Android APK → Artifacts → DualMind-debug-apk.

This is an experimental debug build. Cloud API use requires provider credentials and network access. The application does not impose its own daily message quota; provider limits still apply.
